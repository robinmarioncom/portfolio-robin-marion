Images de projets
=================

Ajoute ici les visuels du portfolio quand ils seront prêts.

Structure conseillée :

- black-bobun-week/
- maison-bellevie-campagne-parfum/
- obobun-personas-analyse-statistique/
- etc.

Dans `app.js`, chaque projet peut recevoir une propriété :

```js
image: "./assets/projects/nom-du-projet/cover.jpg"
```

La fiche projet peut aussi être enrichie avec plusieurs images plus tard.
